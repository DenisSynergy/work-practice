# work-practice

Производственная практика: решение кейс-задачи № 3.

## Описание

Консольное приложение на C#. Пользователь вводит количество сотрудников,
затем данные каждого (Ф.И.О., должность, зарплата, год приёма). После ввода
программа запрашивает порог стажа и выводит список сотрудников, чей стаж
в организации превышает заданное значение.

## Структура проекта

- `Program.cs` — точка входа: диалог с пользователем, создание объектов, фильтрация, вывод результатов
- `Worker.cs` — класс Worker (сотрудник): поля, конструкторы, сеттеры с валидацией, геттеры, расчёт стажа
- `InputHelper.cs` — вспомогательный класс: безопасный ввод строк, целых и дробных чисел с проверкой диапазона

## Требования

- .NET 6.0 или новее
- Visual Studio 2022 (или другая среда с поддержкой C#)

## Запуск

Вариант 1 — командная строка (из папки с файлами проекта):
- `dotnet run` — если проект оформлен как проект .NET
- либо компиляция вручную: `csc Program.cs Worker.cs InputHelper.cs -out:SynWorkApp.exe`, затем запуск `SynWorkApp.exe`

Вариант 2 — Visual Studio:
- открыть файлы, скомпилировать и запустить (Ctrl+F5)

## Особенности реализации

- Инкапсуляция: все поля класса Worker приватные, запись только через сеттеры с валидацией
- Двухуровневая проверка данных: InputHelper (диалог с пользователем) и сеттеры класса (защита полей)
- Обработка исключений: единый блок try/catch с цветным выводом сообщений об ошибках
